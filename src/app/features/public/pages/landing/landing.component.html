Dúvidas frequentes

Preciso cadastrar cartão para testar?

Não. O teste gratuito dura 3 dias e não solicita cartão. Você só realiza o pagamento via PIX se decidir assinar após esse período.

Vou receber alguma cobrança automática?

Não. Ao final do teste, você decide ativamente se deseja assinar e realiza o pagamento via PIX. Não guardamos dados do seu cartão ou conta.

O que acontece depois dos 3 dias?

O acesso às funcionalidades fica pausado, mas seus dados permanecem seguros e salvos. Ao assinar, você continua exatamente de onde parou.

Posso usar no celular?

Sim. O sistema possui uma interface responsiva projetada especificamente para funcionar tão bem no celular quanto no computador.

Quais recursos estão incluídos?

Dashboard analítico, movimentações por mês, criação de categorias personalizadas, recorrências, acompanhamento de contas pagas e pendentes, além de exportação CSV de todos os dados.

Como funciona o pagamento?

O pagamento é realizado exclusivamente via PIX através do Mercado Pago. Depois da confirmação, que geralmente leva segundos, o acesso é liberado automaticamente.
